# Security policy

This policy covers every repository of [Nhat Nguyet](https://github.com/Nhat-Nguyet) that has no `SECURITY.md` of its own.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

- Preferred: **Report a vulnerability** on the Security tab of the affected repository (GitHub private vulnerability reporting).
- Or email **lienhe@nhatnguyet.org** with "Security" in the subject.

Include the repository and version or commit, what an attacker can do, and the smallest input or steps that show it. You will get a reply within 3 working days and a status update at least every 7 days until the issue is closed. Once a fix is released we credit the reporter, unless you prefer not to be named.

## Scope

In scope: code and data published in our repositories, the embed script `https://nhatnguyet.org/embed/w.js`, and the public API under `https://api.nhatnguyet.org`.

Out of scope: denial of service by sending large volumes of traffic, reports from automated scanners without a demonstrated impact, and social engineering.

Please test only against your own installation or with ordinary use of the public site, and do not access other people's data.
