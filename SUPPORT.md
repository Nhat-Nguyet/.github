# Getting help

- **Questions and ideas:** the Discussions tab of the repository.
- **Bugs and wrong results:** open an issue with the input, the output you got, and the output you expected.
- **Security problems:** see [SECURITY.md](SECURITY.md), never a public issue.
- **Anything else:** lienhe@nhatnguyet.org.

Documentation for the libraries: https://nhatnguyet.org/en/ma-nguon-mo/tai-lieu
